# Bellabeat Smart Device Usage Analysis

##  Project Overview

This project analyzes smart device usage data to understand consumer activity and wellness tracking patterns and identify marketing opportunities for Bellabeat.

The analysis was conducted using SQL Server and Power BI, with the findings applied to **Bellabeat Leaf**.

##  Business Task

The analysis answers three key questions:

1. What are some trends in smart device usage?
2. How could these trends apply to Bellabeat customers?
3. How could these trends help influence Bellabeat marketing strategy?

##  Tools

- SQL Server
- Power BI
- Excel
- GitHub

##  Data

The analysis uses Fitbit smart-device usage data covering **March 12 – April 12, 2016**.

The analysis includes daily activity, hourly activity, and sleep-tracking data.

##  Key Findings

- Users averaged **6,547 daily steps**.
- **Wednesday** had the highest average daily steps (**7,511**), while **Tuesday** had the lowest (**4,915**).
- Hourly activity peaked around **7 PM**, with approximately **529 average steps**.
- Users spent an average of **995 minutes sedentary** per day compared with **200 minutes in active categories**.
- **35 users** recorded activity data; **23** also recorded sleep data, while **12** were activity-only users.
- Tracking consistency ranged from **8 to 32 days**.

##  Recommendations

Based on these findings, Bellabeat could:

- Launch activity and movement campaigns.
- Encourage users to reduce sedentary time through reminders.
- Introduce challenges and streaks to improve consistent usage.
- Increase awareness of sleep and other wellness features.
- Use evening activity patterns for timely engagement and personalized messaging.

##  Recommended Product

The insights are applied to **Bellabeat Leaf**, with a focus on encouraging consistent usage, daily movement, wellness tracking, and customer engagement.
